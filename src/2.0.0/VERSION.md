# Version 2.0.0: Modular Architecture & Foundation

**Target Release:** November 2026  
**Status:** In Development  
**Theme:** "Same Great Game, Clean & Scalable Code"  
**Goal:** 100% gameplay parity with Version 1.0.0, restructured into clean modular TypeScript & Vite.

---

## 🎯 What is Version 2.0.0?
Version 2.0.0 takes the complete, working gameplay of Version 1.0.0 and rebuilds it using modern software architecture. The game looks, feels, and plays identically to 1.0.0, but under the hood, the 7,500-line monolith is broken into clean, focused modules.

---

## 🚀 Key Improvements Over 1.0.0

| Feature | Version 1.0.0 | Version 2.0.0 |
| :--- | :--- | :--- |
| **Code Structure** | 1 monolithic file (7,575 lines) | Clean, decoupled modules (`core/`, `scene/`, `physics/`, `data/`, `ui/`) |
| **Development Experience** | Edit 1 huge file, manual refresh | Instant Hot-Module Reloading (HMR) via Vite |
| **Type Safety** | Plain vanilla JavaScript | TypeScript (catches bugs before you even run the game) |
| **Player & Rule Editing** | Deep in 7k lines of code | Simple configuration files (`players.ts`, `courtConfig.ts`) |
| **Sharing Method** | Send raw 7k-line HTML file | Send single optimized bundle (`dist/index.html`) generated by build tool |
| **Future Readiness** | Hard to add audio or new modes | Prepared for real audio, tournament brackets, and online 1v1 |

---

## 📂 Module Breakdown in 2.0.0

- **`data/`**: Player rosters, stats, taglines, pitch dimensions, and scoring rules.
- **`scene/`**: The 3D world (Boca de Vaca pavilion, Endeavour & Baleno vehicles, Goan flora, spectators).
- **`entities/`**: 12-joint human stick figure rig, ball mesh, neon stumps.
- **`physics/`**: Pitch trajectory, one-bounce calculations, spin break deflections, and bat contact math.
- **`gameplay/`**: Batting swing engine, bowling aim/timing needle, umpire rules, and match state machine.
- **`ui/`**: TV broadcast scoreboard, ball dots, broadcast toasts, and Mortal Kombat draft grid.
- **`audio/`**: Centralized sound manager ready for realistic street cricket sfx.

## 🛠️ How to Work With 2.0.0 (Vibe Coder Guide)

- **To play & test while developing:**
  ```bash
  npm run dev
  ```
  Opens `http://localhost:5173`. Any change immediately updates on screen.

- **To produce a single shareable file:**
  ```bash
  npm run build
  ```
  Builds `dist/index.html` (all code & styles packed into 1 file). Share it over Slack/WhatsApp—recipients just double-click to play!
